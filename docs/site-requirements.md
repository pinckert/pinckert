## 2. Audience

Who I expect to use the site:

- Family for photos
- D&D Group for images, maps and session summaries
- Billiard league teammates
- Retirement community members
- General public for blog posts, general information
- Me, for all of the above

## 3. Overall Character

How I want the site to feel.

- Professional appearance
- Easy to navigate. My previous site had a folder navigation routine. Not very secure but allowed visualization of the file system without the need to run an additional application. I would like to maintain this ability but with an .htaccess/.htpasswd (or other) security measure.
- Informal where appropriate
- Not overly trendy
- Desktop prioritized over mobile. Ideally it will be easy to port to a mobile application but given that introduces a requirement to maintain two applications it is a lower priority
